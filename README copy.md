# jev-demos

Demos do Jev (TypeSafe), um modelo de decisão que devolve respostas tipadas com
probabilidades em vez de texto.

| Demo | O que faz |
|---|---|
| [skill-validator](skill-validator/) | Valida uma Agent Skill: regras locais + avaliação semântica (Score/Noul) pelo Jev. |
| [story-sizer](story-sizer/) | Sugere o t-shirt size de User Stories do Azure DevOps (Choice + Score + Noul) numa interface web. |
| [catalog-ai](catalog-ai/) | Catálogo de skills, MCPs e plugins com busca enquanto se digita: ~115 decisões (Choice + Noul) por busca em ~450 ms. |
| [brand-live](brand-live/) | Uma marca que muda enquanto a pessoa fala: voz → ~10 decisões (Choice + Score + Noul) por frase → peças de um catálogo aplicadas em tempo real. |
