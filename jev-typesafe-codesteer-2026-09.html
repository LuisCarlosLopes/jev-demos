Segundos para cinco palavras

O LLM gera a resposta token a token. Um JSON curto ainda custa uma geração inteira.

Contrato frágil

O formato depende do prompt. JSON inválido, truncado ou fora do enum vira código defensivo no nosso lado.

Certeza sem medida

A resposta vem sempre convicta. Não existe um número que diga "aqui falta contexto, não automatize".

‹O que é o Jev

Uma chamada de função com inteligência de modelo de fronteira

decisão = Jev(state, [perguntas tipadas])
Entra um estado não estruturado (card, diff, log). Sai um Decision<T>: o valor escolhido dentro de um espaço declarado antes, a distribuição de probabilidades e a confiança. Nenhuma frase, nenhum "olá".
  • QuemTypeSafe AI, fundada em 2024. O CEO, Diogo Almeida, trabalhou na OpenAI em RLHF, InstructGPT e ChatGPT.
  • QuandoLançado em 15/09/2026, em early access com lista de espera.
  • Por que "System One"Referência a Kahneman: decisão rápida e intuitiva, sem cadeia de raciocínio. Modelos de reasoning são o System 2.
  • Como é treinadoRLCD (Reinforcement Learning for Calibrated Decisions): o alvo é probabilidade calibrada, não agradar quem lê.

‹Por que "System One"

O cérebro decide quase tudo no automático, e só pensa devagar quando precisa

A intuição não é nada mais e nada menos que reconhecimento.Herbert Simon, citado por Kahneman em Rápido e devagar (2011)
Sistema 1 · rápido
Sistema 2 · devagar
Como funciona
Automático, sem esforço, reconhece padrões
Deliberado, com esforço, raciocina passo a passo
No dia a dia
Perceber raiva num rosto; responder 2 + 2; dirigir numa rua vazia
Calcular 17 × 24; estacionar numa vaga apertada; conferir um argumento lógico
De onde vem a resposta
Da memória: experiência acumulada vira reconhecimento
Da atenção: a resposta é montada do zero
Na IA
Jev: estado → decisão, em milissegundos
LLM com raciocínio: pensa antes de responder, em segundos ou minutos
No cérebro, o Sistema 2 só é chamado quando o Sistema 1 hesita. No nosso código é igual: confiança alta, o Jev decide; confiança baixa, a decisão sobe para um LLM de raciocínio ou para uma pessoa.
Diferença importante: o Sistema 1 humano erra com convicção. A aposta da TypeSafe é que o Jev diga o quanto está seguro; se essa confiança é bem calibrada, ainda precisa ser medido.

‹Como funciona

Três tipos de pergunta que viram enum, escala e booleano

Choice
escolha entre opções
Qual destas opções?
Até 255 opções declaradas. Inclua sempre uma saída de escape, como outra.
{ "choice": "NEGOCIO",
  "probabilities": {…},
  "confidence": 0.91 }
Score
escala de níveis
Qual nível numa régua?
De 2 a 10 níveis ordenados. O score é a média ponderada; o nível vencedor é o de maior probabilidade.
{ "score": 1.02,
  "probabilities": {"1": 0.84,…},
  "confidence": 0.82 }
Noul
sim ou não, com probabilidade
Esta afirmação é verdadeira?
Devolve uma probabilidade de 0 a 1. Use faixas: abaixo de 0,30 é não, acima de 0,70 é sim, no meio é incerto.
{ "mexe_em_auth": 0.97 }

# sem campo confidence
Várias perguntas, um requestCada pergunta é avaliada em paralelo e isolada contra o mesmo state. Mais perguntas quase não mexem na latência.
Nunca erra o tipoA resposta não sai do espaço declarado. Não há parse, retry de formato nem enum inválido.
Pergunte pequeno, componha em códigoEm vez de "avalie este PR", pergunte tipo, risco e área separadamente. O peso de cada um fica no nosso código.

‹A parte que muda o desenho

A confiança vira regra de negócio, versionada no código

from typesafe_sdk import TypeSafeClient

client = TypeSafeClient(model="jev-latest", timeout=2.0)
r = client.system_one(state=comentario_do_card,
                      questions=PERGUNTAS_RETRABALHO)
d = r.choices["intencao"]

if d.confidence >= LIMIAR[acao].auto:      # ex.: 0,90
    despachar(d.choice)          # sem toque humano
elif d.confidence >= LIMIAR[acao].sugerir: # ex.: 0,50
    sugerir_ao_operador(d.choice) # aprova com 1 clique
else:
    escalar(d)                   # LLM de raciocínio ou pessoa

registrar(d.probabilities, d.confidence)  # calibrar depois
> 0,90

Automatiza

A decisão segue sozinha.

0,50–0,90

Confirma

Vira sugestão para uma pessoa aprovar.

< 0,50

Escala

Sobe para um LLM de raciocínio ou uma pessoa. Confiança baixa é informação útil, não falha.

O limiar varia com o risco da ação. Uma leitura aceita confiança menor que uma ação destrutiva. Faixas sugeridas na documentação da TypeSafe.

‹Leitura crítica

        
O que o Jev não resolve

        

        

          
"Não alucina" vale para o tipo
Devolver FEATURE onde era BUG é válido no tipo e errado no conteúdo. A garantia é de formato, não de acerto.

          
Os números são do fornecedor
Evals feitos pelo próprio time da TypeSafe, que chama o caso citado de "extremo superior". Sem paper técnico publicado.

          
Inglês primeiro
A documentação diz que outros idiomas não funcionam igualmente bem. Nossos cards são em pt-BR: é o risco número um a medir.

          
Só texto, e não é calculadora
Até 64k tokens por request. Contas, datas e comparação de números ficam no código.

          
Probabilidade não é portão
Um quality gate aprova ou reprova de forma reproduzível. O Jev propõe; o portão determinístico decide.

          
Early access
Lista de espera e créditos. Não dá para colocar em produção agora, mas dá para testar o paradigma.
